# Projet Web blog
> Par CRAVELLO Thomas et GRENIER-VILLENEUVE Nathan

## Présentation
Ce projet a été développé dans le cadre d'un TP lié au développement WEB, il s'agit d'un WebBlog sur la musique. Il permet à un utilisateur de publier
des images, des vidéos ainsi que des avis sur des moments de sa vie (liés à la musique).

## Hébergement 
Le projet est hébergé sur le site web : 
https://projetweb-ciel-cravello-grenier.infinityfree.io/

Ce projet web est un blog web sur la musique créé dans le cadre d'un TP web, il contient :
- 4 à 5 pages accessibles via un menu
- les pages contiennent des images, des vidéos et des textes
- une zone permettant a l'utilisateur principal de se connecter à fin de partager du nouveu comptenu pour le blog
- une page web étant dotée d'un "caroussel"
