# Projet Web blog
> Par CRAVELLO Thomas et GRENIER-VILLENEUVE Nathan

## Présentation
Ce projet a été développé dans le cadre d'un TP lié au développement WEB, il s'agit d'un WebBlog sur la musique électronique. Vous retrouverez dans ce web blog des artistes ainsi que des exemples de leurs projets, personnels ou en collaboration avec d'autres artistes.

## Hébergement 
Le projet est hébergé sur le site web : 
https://projetweb-ciel-cravello-grenier.infinityfree.io/


## Fiche technique

|    technologie utiliser  |HTMl,CSS,JS|

Ce projet web est un blog web sur la musique électronique créé dans le cadre d'un TP web, il contient :
- 4 à 5 pages accessibles via un menu ;
- les pages contiennent des images, des vidéos et/ou des textes ;
- une zone permettant a l'utilisateur principal de se connecter afin de partager du nouveau contenu pour le blog ;
- une page web dotée d'un "carrousel"
